# Smart Sadya

Universal event and food management platform.

## Stage 1 — Foundation (in progress)

- Next.js App Router + TypeScript starter
- Responsive Malayalam-first homepage preview
- No live booking, payments or database connected yet

## Local development

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Security

Never commit API secrets, service-role keys, personal guest data, or real payment credentials. Supabase schema and RLS must be reviewed before any production connection.
